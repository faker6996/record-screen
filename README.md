# Record Screen

Cross-platform desktop screen recorder built with Tauri, React, and Rust.

## Workspace

- `apps/desktop`: React launcher and settings UI
- `src-tauri`: Desktop shell, window lifecycle, Tauri commands
- `crates/*`: Recording domain, platform backends, settings, telemetry
- `docs/`: Architecture notes, roadmap, and UX plan

## Commands

```bash
npm install
npm run dev
npm run lint
cargo check
```
